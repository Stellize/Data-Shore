# Tide Atlas

A small working archive of the **Tide Atlas** — six years of shore observations from the
Lampang coast and the islands beyond it. Photographs, field notes, a reader's companion,
and two recordings made at the water's edge.

This folder is published by a Data Shore node as a **read-only** archive. Nothing here can be
edited or deleted through the web. If you are reading this on a public shore, you are a guest:
look, listen, download — the originals stay on the keeper's drive.

## What is inside

| Folder | Contents |
| --- | --- |
| `essays/` | Two long-form essays in Markdown |
| `field-notes/` | Tide tables, species lists, coordinates |
| `photographs/` | Estuary and headland plates with captions |
| `audio/` | Field recordings (MP3) and recording notes |
| `video/` | A short low-tide walk (MP4) |
| `documents/` | The reader's companion (PDF) |
| `archives/` | Tide tables 2019–2025 as a ZIP |

## A note on care

These are working notes, not finished science. Where a number looks precise, it was probably
measured with cold hands. Treat the tables as a record of attention rather than an instrument
for navigation.

— *The keeper, October 2026*
